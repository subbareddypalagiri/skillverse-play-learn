## 🚨 **Troubleshooting**

### **Problem: "API Error" or "Failed to load"**

✅ **Solution:**
1. Check `.env` file - is your API key correct?
2. Check internet connection
3. Verify you're subscribed to FREE plan on RapidAPI
4. Look in browser console for error details

### **Problem: "No internships showing"**

✅ **Solution:**
1. Wait 5-10 seconds (API takes time)
2. Check browser console for errors
3. Try refreshing the page
4. Check if you exceeded 2500 requests this month

### **Problem: "Invalid API Key"**

✅ **Solution:**
1. Double-check you copied the FULL key
2. No extra spaces before/after the key
3. Make sure you saved the `.env` file
4. Restart dev server (`npm run dev`)

## 🎯 **Quick Reference**

### **API Endpoint:**
```
https://jsearch.p.rapidapi.com/search
```

### **Your Headers:**
```
X-RapidAPI-Key: [Your Key]
X-RapidAPI-Host: jsearch.p.rapidapi.com
```

### **Query Parameters:**
- `query` - Search term (e.g., "internship")
- `page` - Page number (default: 1)
- `num_pages` - Pages to fetch (default: 1)
- `date_posted` - all, today, 3days, week, month
