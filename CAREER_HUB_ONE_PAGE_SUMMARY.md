## 🎯 Supported Queries

```javascript
// Search by title
/api/jobs/all?search=developer

// Filter by type
/api/jobs/all?type=Internship

// Filter by location
/api/jobs/all?location=USA

// Pagination
/api/jobs/all?page=2&limit=12

// Combined
/api/jobs/all?type=Full-time&location=USA&search=python

// Advanced search
POST /api/jobs/search {
  title: "developer",
  skills: ["React"],
  remote: true
}
```
