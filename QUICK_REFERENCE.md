## 🎨 **Post Creation Flow**

1. Click **"Create Post"** button
2. Select post type
3. Add title & description
4. Paste media URL (or upload file in production)
5. Add category/tags
6. Click **"Post"**
7. See it in feed!

---

## 🔗 **Platform Integration Flow**

1. Go to **"Connect Platforms"** tab
2. Click on platform card (e.g., GitHub)
3. Enter your username
4. Click **"Import Data"**
5. Stats appear on your profile!

---

## 📊 **What Gets Imported**

### GitHub:
- Number of repositories
- Stars earned
- Followers count
- Contributions (last year)

### LeetCode:
- Problems solved
- Global ranking
- Earned badges

### Other Platforms:
- Similar achievement data
- Profile links
- Activity stats

## 🎮 **Engagement Mechanics**

### Like System:
- Click heart → Turns red
- User gets notification
- Like count increases
- Dopamine hit! 💖

### Comment System:
- Click comment icon
- Opens comment dialog
- Type comment
- Press Enter or click Send
- Comment appears
- Post owner notified

### Share System:
- Click share icon
- (Future: Share to other platforms)
- Share count increases
